# Makiety — przegląd wyglądu WSB (26.11.2026)

`przed/` — stan obecny (Szoko, kopia lokalna). Makiety (HTML + PNG):

- `konsola-A-dzis` — pulpit „Dziś”: pasek przepływu zamówień zamiast ośmiu kafelków, lista „Do zrobienia teraz”.
- `konsola-B-tablica` — pulpit „Tablica”: zamówienia jako kolumny przepływu.
- `konsola-zamowienia` — lista zamówień: kroki jako zakładki, stan = kropka + słowo, akcje grupowe.
- `konsola-mobile` — telefon: dolny pasek z przyciskiem Skanera.
- `sklep-katalog`, `sklep-produkt-mobile` — sklep w stylu Szoko (każdy sklep zachowuje swój design system).
- `siedziba` — siedziba WSB: wszystkie sklepy, obrót, rachunek, stan, wersja. Liczby innych sklepów są przykładowe.

Konsola: jedna rodzina Archivo, chłodne szarości, kolor sklepu tylko jako akcent.
